## Timeline

Hiển thị tiến trình sự kiện theo chiều dọc hoặc ngang.

```tsx
<Timeline items={[{ date: "20/10", title: "Đặt phòng", status: "success", icon: "✓" }]} variant="advanced" />
```

`variant`: `default`, `compact`, `advanced`, `stepper`.

`advanced` hỗ trợ thêm `icon`, `badge`, `action`; `stepper` phù hợp luồng nhiều bước.
