## Loading

Spinner biểu thị tác vụ đang xử lý hoặc dữ liệu đang tải.

### Để làm gì

- Cho người dùng biết hệ thống đang phản hồi, tránh thao tác lặp.
- Dùng trong vùng fetch dữ liệu, nút submit hoặc bước đồng bộ.

### Khi nào sử dụng

- Đang tải phòng trống, báo giá hoặc lịch onsen.
- Đang tạo đặt phòng, ghi nhận thanh toán hoặc xuất hóa đơn.

### Demos

```tsx
<Loading size="sm" label="Đang tải..." />
<Loading size="md" label="Đang đồng bộ dữ liệu..." />
<Loading size="lg" label="Đang tạo báo cáo..." />
```

### API

| Prop | Type | Default | Mô tả |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Kích thước spinner. |
| `label` | `string` | `'Đang tải...'` | Nhãn hiển thị và hỗ trợ screen reader. |
| `className` | `string` | `''` | Tailwind class bổ sung. |

### Ghi chú

- Component có `role="status"` để hỗ trợ công cụ đọc màn hình.
- Chỉ dùng khi tác vụ có độ trễ dễ nhận thấy.
