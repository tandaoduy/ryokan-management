## Badge

Badge là nhãn ngắn để biểu thị trạng thái, phân loại hoặc số lượng. Hỗ trợ icon, dot, loader, link và dismiss ở cả light/dark mode.

### Khi sử dụng

- Trạng thái đặt phòng, thanh toán hoặc tình trạng phòng.
- Phân loại khách, gói dịch vụ hoặc nhãn ưu tiên.

### Ví dụ

```tsx
<Badge variant="success">Đã xác nhận</Badge>
<Badge variant="warning" appearance="outline">Chờ thanh toán</Badge>
<Badge variant="danger" appearance="solid">Đã hủy</Badge>
<Badge dot variant="success">Đang hoạt động</Badge>
<Badge loading variant="info">Đang đồng bộ</Badge>
```

### API

| Prop | Type | Default | Mô tả |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Nội dung ngắn của nhãn. |
| `variant` | `'neutral' \| 'info' \| 'success' \| 'warning' \| 'danger'` | `'neutral'` | Ý nghĩa và màu trạng thái. |
| `appearance` | `'soft' \| 'solid' \| 'outline'` | `'soft'` | Cách thể hiện nền/viền. |
| `size` | `'sm' \| 'md'` | `'md'` | Kích thước badge. |
| `shape` | `'rounded' \| 'pill'` | `'pill'` | Kiểu bo góc. |
| `icon` | `ReactNode` | — | Icon ở đầu badge. |
| `dot` / `loading` | `boolean` | `false` | Chấm trạng thái hoặc loader. |
| `href` | `string` | — | Render badge dưới dạng link. |
| `dismissible` | `boolean` | `false` | Hiển thị nút đóng badge. |
| `className` | `string` | `''` | Class Tailwind bổ sung. |

### Ghi chú

- `soft` là lựa chọn mặc định cho danh sách và bảng dữ liệu.
- Dùng `solid` cho thông tin cần nhấn mạnh, còn `outline` cho nội dung phụ.
